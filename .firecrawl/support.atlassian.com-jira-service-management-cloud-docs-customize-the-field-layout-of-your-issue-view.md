# Customize the field layout of your work item view

Customizing the fields that appear on your team’s work items can help your team resolve them faster. For example, if there are some fields that you fill out for _every_ work item, it makes sense for those fields to be visible and located somewhere towards the top of each work item view.

Each space has its own work item layout. You can’t share work item layout settings between spaces right now. [Find out how to add fields that don't appear in the work item layout screen](https://confluence.atlassian.com/get-started-with-jira-core/configure-field-layout-in-the-issue-view-962349445.html#Configurefieldlayoutintheissueview-addfields "https://confluence.atlassian.com/get-started-with-jira-core/configure-field-layout-in-the-issue-view-962349445.html#Configurefieldlayoutintheissueview-addfields").

You must be an admin to configure the field layout in the work item view.
